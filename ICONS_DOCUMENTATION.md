## 🛠️ Installation & Utilisation

### Installation
```bash
npm install lucide-react
```

### Exemple d'utilisation
```jsx
import { Briefcase, Download, Plus } from 'lucide-react'

function Mission() {
  return (
    <div>
      <button><Plus size={20} /> Nouvelle Mission</button>
      <icon icon={Briefcase} size={24} className="text-blue-600" />
      <button><Download size={18} /> Exporter</button>
    </div>
  )
}
```

### Personnalisation
```jsx
// Taille
<MyIcon size={16} />      // Petit (16px)
<MyIcon size={24} />      // Moyen (24px)
<MyIcon size={32} />      // Grand (32px)

// Couleur
<MyIcon className="text-red-500" />
<MyIcon color="#FF0000" />

// Épaisseur
<MyIcon strokeWidth={1.5} />  // Mince
<MyIcon strokeWidth={2} />    // Normal
<MyIcon strokeWidth={2.5} /> // Épais
```

## 🎯 Bonnes Pratiques

1. **Cohérence** : Utiliser les mêmes icônes pour les mêmes actions
2. **Taille** : Adapter la taille au contexte (navigation = 20-24px, boutons = 16-18px)
3. **Couleur** : Respecter la palette de couleurs du design system
4. **Accessibilité** : Toujours associer une icône à un texte explicite
5. **Performance** : Les icônes Lucide sont ultra-légères (< 1KB chacune)
