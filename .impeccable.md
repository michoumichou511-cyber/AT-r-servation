# AT Réservations — Design context

> Généré via **teach-impeccable**. À mettre à jour si la charte ou le périmètre métier change.

## Design Context

### Produit

- **Nom** : AT Réservations  
- **Organisation** : Algérie Télécom — **plateforme interne** (usage professionnel, pas grand public).  
- **Stack UI (référence codebase)** : React (Vite), Tailwind CSS, Framer Motion, Recharts ; police **IBM Plex Sans** (et Plex Mono pour données type références / montants).

### Users

- **Qui** : collaborateurs Algérie Télécom (rôles typiques : administrateur, valideur, demandeur / utilisateur selon le métier).  
- **Contexte** : bureau ou poste connecté au réseau / outils internes ; sessions parfois longues (missions, validations, budgets).  
- **Objectif** : accomplir des tâches **rapidement et sans erreur** (création / suivi d’ordres de mission, validations, messagerie, reporting).  
- **Émotion cible** : **confiance**, **clarté**, **sérieux** — interface rassurante, jamais “gadget” ni trop ludique.

### Brand Personality

- **3 mots** : **professionnel**, **sobre**, **moderne** (aligné avec ta consigne).  
- **Voix** : factuelle, polie, directe ; libellés en français clair.  
- **Alignement marque** : couleurs institutionnelles AT (voir ci-dessous), pas de palette “startup” flashy.

### Aesthetic Direction

- **Ton visuel** : sobre, structuré, type **outil métier premium** (dashboards, tableaux, formulaires lisibles).  
- **Couleurs de marque (obligatoires)**  
  - **Vert** : `#00A650` (actions positives, validation, accents primaires)  
  - **Bleu** : `#003DA5` (titres forts, liens importants, second accent institutionnel)  
- **Tokens déjà présents dans le code (Tailwind)** : `at-green`, `at-blue`, variantes `-light` / `-dark` ; fonds type `#F4F6FA`, cartes blanches, bordures `#EAECF0` / gris discrets.  
- **Dégradés** : réservés aux **CTA** ou highlights (ex. vert → bleu), toujours **modérés**, jamais arc-en-ciel.  
- **Mode sombre** : supporté (`darkMode: 'class'`) — fonds sombres lisibles, pas de contraste insuffisant sur texte secondaire.  
- **Anti-références** : éviter l’esthétique “template IA” (illustrations stock génériques partout, Inter partout sans personnalité, néomorphism excessif, animations qui distraient du travail).

### Design Principles

1. **Lisibilité avant tout** : hiérarchie typo claire, espacements généreux sur les formulaires et tableaux.  
2. **Cohérence AT** : vert / bleu et grilles alignées avec les écrans existants ; pas d’introduction de couleurs hors charte sans validation.  
3. **Sobriété animée** : micro-interactions utiles (hover, transitions courtes) ; **pas** d’animations décoratives qui ralentissent la saisie.  
4. **Accessibilité de base** : contrastes suffisants sur vert / bleu sur fond clair ; boutons et zones cliquables explicites ; respecter `prefers-reduced-motion` pour les animations non essentielles quand c’est pertinent.  
5. **Mobile secondaire** : l’usage principal reste desktop ; le responsive doit rester utilisable sans sacrifier la densité d’info utile au métier.
