📋 Information et Guide d'utilisation

Navigation : L'application utilise Lucide React v0.577.0 pour tous les icônes. Chaque icône est importée depuis le package 'lucide-react'.
Catégories : Les icônes sont organisées par fonctionnalité pour une meilleure navigation et compréhension de l'interface.
Utilisation : Pour importer une icône, utilisez import { NomDeLIcone } from 'lucide-react'
Personnalisation : Chaque icône peut être redimensionnée avec la propriété size et coloriée avec className ou color.
Responsive : Les icônes utilisées s'ajustent automatiquement en fonction du contexte (32px, 24px, 16px, etc.).
Package.json : Assurez-vous que lucide-react est installé : npm install lucide-react
