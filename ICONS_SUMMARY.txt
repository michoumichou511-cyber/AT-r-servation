─────────────────────────────────────────────────────────────────────────────

PROPRIÉTÉS PRINCIPALES :
─────────────────────────────────────────────────────────────────────────────
  size={16|18|20|24|32}     → Taille en pixels (par défaut: 24px)
  className="text-red-500"  → Couleur Tailwind CSS
  strokeWidth={1.5|2|2.5}   → Épaisseur du trait
  color="#FF0000"           → Couleur hexadécimale

📝 NOTES POUR LE MÉMOIRE
═══════════════════════════════════════════════════════════════════════════════

Les 93 icônes utilisées dans AT Réservations représentent une couche de 
présentation cohérente et professionnelle. Chaque icône:

  • Facilite la compréhension intuitive des actions
  • Améliore l'accessibilité pour tous les utilisateurs
  • Respecte le design system global de l'application
  • Est optimisée pour le web et les appareils mobiles

La librairie Lucide React a été choisie pour sa:
  ✓ Qualité graphique constante

  ✓ Personnalisation facile
  ✓ Communauté active et support excellent
  ✓ Compatibilité avec React et Tailwind CSS
